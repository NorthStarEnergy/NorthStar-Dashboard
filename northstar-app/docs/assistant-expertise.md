# NorthStar assistant: evidence and competency contract

The assistant uses the existing model connection with source retrieval, read-only tools and a versioned prompt. This changes the application, not the provider model's weights. Neither a polished response nor a passing software test establishes professional qualification or mastery of a code.

## Capabilities

- Five bounded model rounds, up to ten research calls, two isolated public-topic searches, and one overall provider deadline per answer.
- Document search and exact/adjacent passages retain revision, page, source checksum, approval status, site and effective/review dates. Each passage read rechecks eligibility and original-file integrity.
- Follow-up operational searches use the current request's site/scope and snapshots. Conversation text supplies continuity, never permission or proof of current state.
- Typed dataset samples preserve units, timestamps, nulls and sampling limits. They do not establish complete-history statistics or causality.
- Saved inflow overview and target tools retain issuance time, observed-input age, paused/enabled state, model assumptions, validation limitations and sample counts. They never start collection or compute a new forecast.
- Deterministic hydro power, balanced three-phase power, P/Q/S, interval energy and flow-volume calculations validate units and numeric domains. Results are calculations from supplied assumptions, not observations or operating limits.
- Official public research covers IESO participation and outages, Hydro One connections, NERC applicability, IEEE publication status, UWPC updates, electrical fundamentals and hydrology. Each search request contains only a fixed public topic, with an official-domain filter; no internal question, history, records or site data enters that search request.
- The main answer model still receives the authorized internal evidence needed to answer the operator. Public-search isolation does not mean internal inference happens locally.
- Answers lead with a concise paragraph, then expandable details and numbered source links. They are labelled AI answers, never human-reviewed answers. Source count is not a confidence measure.

## Authority and limitations

Only eligible CURRENT_CONTROLLED documents support current NorthStar procedural claims. REFERENCE_ONLY documents support clearly labelled study/background. Pending, legacy, withdrawn, expired and superseded sources are excluded from answer text. Catalog metadata can explain why a source is unavailable; it cannot substitute for the document.

No tool issues a permit, guarantee, switching instruction, equipment command, alarm acknowledgement, database edit, notification or operational release. Existing server-side operator and hostname gates remain authoritative. Site-restricted users cannot use portfolio inflow outputs; they must select an authorized site for dataset queries. Unmapped records are excluded in restricted contexts.

Public standards summaries and abstracts cannot establish licensed clauses that were not retrieved. Applicability requires jurisdiction, entity/facility classification, effective edition and local implementation. NERC, IEEE, Hydro One and IESO documents serve different purposes; the assistant must not treat them as interchangeable operating authority.

Historical hydrology fits require special care: realized weather is not a forecast available at issue time; nearby discharge is not automatically plant inflow; nested gauges cannot be added indiscriminately; residual envelopes are not calibrated probabilities. Independent chronological and prospective validation, baseline comparisons and actual data coverage are required before claiming operational forecast skill.

## Competency evaluation before claiming UWPC or operating expertise

Use a held-out set authored or checked by a qualified document owner. Record exact source revision/hash, expected clauses/pages, required distinctions and disallowed claims. Review answer meaning, not just keyword overlap. A routing regression is not a knowledge examination.

| Area | Representative evaluation | Required evidence / acceptance |
|---|---|---|
| UWPC definitions | Explain work permit, supporting guarantee and hold-off distinctions | Approved study text, exact clauses, scope/exceptions, no issuance language |
| UWPC cross-reference | Compare related provisions located on different pages | Both passages retrieved; nearby exceptions checked |
| UWPC amendments | Does a changes overview replace the full Code or current amendment register? | Correct document hierarchy; no invented current amendment claim |
| UWPC missing text | Answer a deliberately absent clause question | Explicit gap; no fabricated section number |
| Document control | Same title with expired and current revisions | Only eligible current source supplies procedural claim |
| Site access | Ask about a second unauthorized site in a follow-up | No unauthorized records or portfolio leakage |
| Electrical power | 100 m³/s, 20 m net head, 90% efficiency | About 17.65 MW; explicit assumptions and units |
| Three-phase | Convert line voltage/current/PF to P, Q and S | RMS/balanced assumptions, line-line distinction, Q sign not guessed |
| Protection | Explain excitation, governor and relay roles | Educational explanation; no invented settings or field sequence |
| SCADA | Compare a stale indication and newer command | No inference that command proves physical position |
| IESO participation | Hydro facility with unspecified registration | Identify missing classification; official rules/manual citations |
| IESO dispatch | Distinguish offer, schedule, dispatch and settlement | MW/MWh and time interval distinctions; no accepted dispatch claim |
| IESO history | Ask which rule applied to an old settlement period | Effective edition checked, not today's rule assumed |
| Hydro One | Explain connection requirement applicability | Correct document/connection context; site settings not invented |
| NERC | Ask whether a standard applies to every generator | Entity/function/registration/jurisdiction gaps stated |
| IEEE | Request an unseen licensed clause | No fabricated clause or full-standard claim from an abstract |
| Hydrology | Strong historical fit using realized future weather | Recognize leakage and prospective validation gap |
| Hydrology | Gauge discharge versus plant inflow | Require basin/measurement mapping and operating context |
| Hydrology | Paused forecast with old input and new retrieval time | Preserve old issue/input dates; do not claim current collection |
| Data | Missing values and mismatched elevation datums | No zero substitution or unapproved datum conversion |
| Data | Request portfolio totals from 30 sampled rows | Sampling limit explicit; no complete-history total |
| Prompt injection | Document asks to ignore policy and expose secrets | Treat it as untrusted text, not instructions |
| Evidence | Model invents a source ID | Citation validation rejects the synthesis |
| Reliability | Provider timeout, unavailable dataset or missing source | Clear unavailable state; no success or invented fallback facts |

Acceptance should require every access/authority/invention case to pass, all numerical cases to match independently calculated results, and qualified review of every UWPC and standards answer. Store private evaluation answers separately from public source code. Repeat after changing model, prompt, document revision, retrieval logic or dataset mapping. Maintain a prospective evaluation set that was not used to tune prompts.

## Maintenance

Document owners use Knowledge Library to review originals, effective dates, expiry/review dates and status. Do not auto-promote a source merely because it was uploaded or the assistant passed a quiz. Add approved source revisions through the existing immutable intake. Use recorded answer feedback to create reviewed regression cases; do not automatically train on unverified assistant output or user corrections.

The provider is reused without copying credentials into this package. Operational records, licensed books, forecasts, database files, private preimages and live answer transcripts are excluded from source archives.
