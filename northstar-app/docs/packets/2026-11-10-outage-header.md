# Outage Manager navigation

The title and New action share the top row on desktop and mobile. Home, Outages and UWPC are the main menu entries. An operator’s selected outage folder still appears under Outages.

A bell beside New appears when that operator has outstanding alerts. Its count is the number of outages with alerts. It opens assigned review requests, final-copy notices and flagged concerns at the existing inbox address.

Refresh Outage Manager to load the updated header.
