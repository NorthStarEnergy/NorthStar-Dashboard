# Outage Manager

Open **Outages → Outage Manager** or visit `/outage-manager.html` on the operator host. Home opens the upcoming register. In progress shows active outages. Past includes closed or cancelled outages and planned windows that have ended. Passing the scheduled end does not close an outage.

Search by words in the outage name, ID, sites, equipment, scope or owner. Filter by site, type, priority, plan status and start date. Column controls sort the results. The server queries the shared SQLite register and returns up to 30 outages per page. The details control lists the packages attached to an outage.

**New** creates a planned outage and linked work package in one transaction. **My reviews** opens the signed-in operator's assigned reviews, corrections and delivered packages. The standalone package editor uses the existing revision, eligibility, approval, distribution and switching-log controls.

**UWPC library** reads the protected NorthStar knowledge source for the 2024 Code, honoring its access scope and recorded source status. The manual can be searched or read by PDF page, text page and bookmark. The form downloads are original illustration pages from the verified edition. The study questions cite the applicable clause or source page. Document bytes and indexed passages remain in the private source store.
