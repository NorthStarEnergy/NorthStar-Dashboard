# Outage Manager register and working folder

Home and Outages open the complete outage register. Opening a record selects its package as the only folder in the sidebar. The selected outage is highlighted when it appears in the register. Each operator’s browser remembers the last opened outage ID. On first use, the first available row in the displayed register becomes the default.

The register puts period tabs, New outage, search and filters above the first row. Package pages combine the outage name and section on one line. UWPC library precedes My reviews. The reader groups the source PDF link with the manual title and publication status. On phones, the table of contents starts collapsed and opens when searching.

This release updates static assets. Refresh the Outage Manager page to load it.
