# Outage process summaries

The process strip uses phase icons, checkmarks for completed stages and a highlighted current stage. Hover over a phase or focus its link with the keyboard to see its status and recorded details. The summary stays open while the pointer is inside it. Leaving the phase and summary, moving focus away or pressing Escape dismisses it. Selecting a phase still opens its package page.
