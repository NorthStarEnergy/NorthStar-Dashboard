# Outage folders and coordination

Open an outage from Home or Outages to see its overview, scope, work window, sign-off count and forms. The sidebar opens each part of the package as a separate page. The process graphic links to the relevant page and shows outstanding corrections, assigned reviews, the final accuracy check and distribution. Past register entries open through the same navigation.

The request can name an SSC outage manager and a local outage manager. When routing a significant outage in Outage Manager, select one of the scheduled SSCs and a separate on-site representative or the assigned area manager. The SSC coordinates from the control room. The local manager coordinates field crews, the area manager and phone communication with the chair.

The control room manager, scheduled operators, area manager and one field representative per affected site review the package. The independent competent checker signs the coordinated revision last. Content edits withdraw the review and any distributed copy. A correction on an issued coordinated revision requires another independent check. Reviews already in circulation retain their recorded assignments and signing rules until reissue.

After the final check, NorthStar distributes the revision to the outage team, preparer and named viewers. **My reviews** links each recipient to the frozen final copy. Dismissing the alert is optional. A viewer can flag a concern, and the two outage managers receive an inbox alert and can record a resolution. A concern and its resolution are recorded against that copy. A required change uses the package correction and reissue workflow.

Deployment requires a managed backend restart. Existing package links and historical records use the same register and stored documents. The packet changes no operational records or assigned accounts.
