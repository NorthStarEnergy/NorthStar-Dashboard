# Outage distribution and closeout

From **Outages → Current outages**, open **Outage plan** on a planned request. The UWPC Builder carries the request ID, site and work description into the plan. Opening it again returns to the same plan. Add the order, supporting forms and drawing, then route the revision to the assigned reviewers.

When the last required review is complete, NorthStar creates one final ZIP and delivers its download link to the assigned team and any additional recipients. Each recipient can acknowledge receipt. A revision or correction before work starts withdraws the old link. The distribution history retains the recipients, revision and archive hash.

A scheduled SSC or the assigned control room manager opens the electronic switching log. Assigned reviewers can record what happened, the activity time, site and applicable order step. The server records the signer and entry time. Append a new entry to correct an earlier one. The existing authority and permit procedures govern physical operations.

An assigned SSC or manager finishes the outage with a closing summary. For a plan opened from the outage register, this also closes the linked request in the same transaction. The team can append follow-up notes under **Finished / closed** and download the closeout record, which includes a printable switching log. The originally distributed ZIP retains its approved contents.
