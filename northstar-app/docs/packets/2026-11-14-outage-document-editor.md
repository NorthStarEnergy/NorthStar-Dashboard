# Outage Manager document editor

In Forms or Drawings & documents, check out the document and select **Open document editor**. The separate window edits the printable form layout. Select a row to change its font, size, text or fill color. Add a box or bottom line, drag the left border to adjust its inset, or insert a local image. Save changes before checking in.

The operator and visitor interfaces use the existing checkout and revision checks. The backend validates row formatting and images and includes them in the PDF and Excel exports. Deploy the backend and restart the managed service before publishing the visitor site.
