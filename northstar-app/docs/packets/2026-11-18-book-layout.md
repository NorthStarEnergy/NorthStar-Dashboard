# Log Book layout and event filters

The embedded Log Book uses the dashboard’s Edit Layout, grid spacing, snap, Save, and Reset controls. Each panel supports pointer dragging, arrow-key movement, Alt for a one-pixel nudge, Shift for ten steps, and horizontal resizing. Saved positions are local to the operator, page, and desktop or narrow layout. Cancel restores the saved arrangement. Reset previews the default arrangement until saved.

The current event log uses 26-pixel rows. Severity and log shading spans each row. The full message opens from the row. All, Alarms, Critical, and Operator logs are quick filters. Filters adds server-side station, severity, text and source criteria that stay active during refresh.

The packet updates static assets. No service restart or database change is required. Verify with the operator-book and v1-wide-monitor Edge fixtures.
