# r013 schematic viewing improvements

## Result

Full-width drawing with a 75vh viewport, optional device details, and full-screen
review. Native fullscreen is preferred with an in-page overlay fallback.

## Controls

Pointer-centered wheel zoom (10-600%), drag-to-pan with click suppression,
zoom buttons and fit to both dimensions. Keyboard arrows pan a focused viewport;
+/- zoom, 0 fits, and Escape exits fullscreen. Selecting equipment opens details.

## Unverified markings

The draft header, persistent unverified warning and amber device markers remain.
Unresolved controls remain blocked. Fullscreen hides the bus summary to reserve
space; device terminal readings remain available through details. Wires still
show geometry, not energization.

## Scope

Only r013 viewing JavaScript/CSS and documentation changed. No model, topology,
protection, operating state or plant integration changes.

## Validation

Chrome visual checks: fullscreen entry, fit, wheel zoom, drag-to-pan, unresolved
CS1 details with controls blocked, and Escape exit. 72 JavaScript tests pass.
Full Python suite: 628 passed, 21 skipped, 347 subtests passed (160.79 seconds).
The 21 optional PostgreSQL/browser integrations remain unverified. The initial sandbox run
could not create temporary SQLite databases or bind local test sockets.

## Runtime

The local standalone trainer on port 43209 serves the revised assets. Review
exercise remains paused. Existing saved sessions are preserved.

## Remaining uncertainty

Touch-device gestures and other browsers were not physically tested. Native ABB
rendering, as-built acceptance, unresolved wiring and all previous model
assumptions remain unverified; this UI change adds no engineering acceptance.
