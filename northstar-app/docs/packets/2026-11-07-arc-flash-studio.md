# Engineering · Arc Flash Scenario Studio

Engineering registers switching:arc-flash-studio in the standard and baseline dashboard views. The module loads the bundled studio from the authenticated dashboard origin when selected. The six scenarios retain the standalone calculator, reference-table and external study setup workflows. The equipment and protection assumptions remain visible. License and attribution for the calculator are included under arc-flash-studio/vendor.

Verified both installed dashboard views with an isolated Ryan-role fixture in Edge. Each opened all six scenario choices and reached the three-phase calculator, whose default case returned 2.597 cal/cm².
