How collection works

Schedules run while the NorthStar backend is running. Each run rechecks the configured recent window, skips duplicate observations, and keeps revisions when a provider changes a value. “Collect now” uses the same settings even when a schedule is paused. Pausing stops future scheduled runs; an active run can finish. Provider cooldowns apply to both manual and scheduled requests.
