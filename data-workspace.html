Expression guide

Use field names and arithmetic. Supported: ABS, ROUND, SQRT, FLOOR, CEIL, MIN, MAX, COALESCE and IFELSE. Use == for equality and lowercase and / or. Division by zero returns a missing value. These are dataset expressions, not Excel cell references or VBA.

Using the data workspace

Browse and edit

Select a dataset, apply typed filters, choose columns and save personal views. Click a row to edit it and review its history. Concurrent changes are detected before saving.

Calculate

Calculated columns use numeric field names. For example, ROUND(power_mw * interval_hours, 3). Use IFELSE(power_mw > 0, power_mw, 0) for conditions. No Excel/VBA compatibility is implied.

Run a script

Use SET field = expression, one assignment per line, up to eight numeric fields. All expressions use original row values. Preview is required, expires after ten minutes and can be applied once. Records changed since preview are excluded. Jobs commit batches of 250 records and stop after ten minutes.

Graph

Choose a numeric value, date/category and aggregation. Charts show at most 500 groups; narrow filters if that limit is reached. Missing values are excluded from numeric aggregates; sample and valid-value counts are retained.

Dates and exports

Enter record timestamps in your local timezone; they are stored as UTC. Date/time filters require an ISO timestamp with timezone, such as 2026-10-17T00:00:00Z. Page export includes only displayed rows and columns; cells beginning with spreadsheet control characters are escaped.
