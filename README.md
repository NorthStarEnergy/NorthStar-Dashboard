# NorthStar

The repository contains three separate applications:

| Folder | Contents |
| --- | --- |
| [northstar-app](northstar-app/README.md) | Main dashboard, Python backend, desktop client sources, tests, and documentation |
| [northstar-games](northstar-games/README.md) | Poker, Blackjack, Chess, Euchre, bots, and game assets |
| [northstar-manager](northstar-manager/README.md) | Installed Manager source and workstation service-control scripts |

Run each application's setup and development commands from its own folder. See its README for requirements. The app's source and release instructions are in `northstar-app/AGENTS.md`.

This repository preserves source code. Credentials, live databases, saved sessions, logs, and installed dependencies are excluded. Manager's workstation configuration still refers to the existing installation; reorganizing this repository does not move or restart that installation.
