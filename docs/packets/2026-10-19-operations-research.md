# Operations Research repository

Adds Operations → Research with seven curated projects and fourteen original files. Supports project/document search, category filtering, safe text/Markdown reading, byte-preserving downloads and shared Drive folder links. Stores reviewed snapshots in `research/projects`, metadata in `research/catalog.json`, and a generated browser catalogue in `research/catalog.js`.

The revised inflow audit is included with its evidence archive. Related source mapping, workbook automation, public water collection, data infrastructure and daily report references retain dates and limitations; the superseded initial inflow analysis is excluded.

Navigation changes are limited to Research registration and its asset includes. Existing dirty dashboard layout and migration work are preserved. No backend routes, authentication allowlists, operating data or collector schedules changed. Standalone Research waits for the existing operator session and redirects required unauthenticated sessions to sign-in.

Verification: catalogue built from fourteen exact source copies; JavaScript syntax checks completed. Standalone hosted contents were observed before the final session-wait adjustment.
