# Compact dispatch interface

Dispatch is now a compact, content-height card capped at 360px wide instead of a stretched column. APIROQ identity and output share the first row; reserve standby occupies a slim footer. OR activation is a small inline status badge with a live-region label. Redundant site and MW displays are hidden while their existing update targets remain intact. The obsolete dispatch override block was removed and the stylesheet version advanced.

Validation: all dashboard script blocks compile and the layout migration checks pass. No browser visual testing was performed. Python regression results are recorded in the release commit. Only presentation changed; activation behavior and feed logic are unchanged.
