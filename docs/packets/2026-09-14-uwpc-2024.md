# UWPC 2024 governing source — 2026-09-14

The dashboard now uses the 2024 Utility Work Protection Code as the citation for switching and outage work-protection drafts.

## Available behavior

- `northstar_uwpc.py` holds the edition, section list, and instrument names (PC10A, PC17B, PC2, supporting guarantees, PC4, Hold-off, Caution, Terminal Point). It does not store rule text or glossary definitions.
- `GET /api/uwpc` is operator-only and returns that index. `GET /api/uwpc/book` serves a licensed PDF only when the host has one.
- New switching drafts default to rule set `UWPC 2024` and procedure id `uwpc-2024`. The operator picks the Work Permit or tag before qualified review.
- If this host holds `data/controlled-sources/uwpc-2024.pdf` (or `NORTHSTAR_UWPC_PATH`), that book can satisfy the governing-source gate. Otherwise the licensed book is still attached to the draft as before.
- The Outages **UWPC** tab shows the 2024 citation, instruments, and sections. It is not a permit desk.

## Inputs

The owner provided the 2024 Code for the control room to use. The copyrighted book is not committed. Place the licensed PDF at `data/controlled-sources/uwpc-2024.pdf` on the operator host.
